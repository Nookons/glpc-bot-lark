# 🔴 **PyJWT — для осмотров (`/inspection`), и его тут не было.**
#
# Бот выпускает токен работника сам (`inspection_api.issue_token`), и делает это
# через PyJWT. Библиотека стояла **локально** (её поставили руками при
# разработке), но в `requirements.txt` её не было — значит в контейнере
# (`Dockerfile` ставит только этот файл) её **нет**.
#
# **Как это выглядело.** Владелец 17.10.2026: «⚠️ Your Telegram account is not
# linked to a system user (no auth_id) — inspections are unavailable». При этом
# привязка была, `auth_id` в карточке был — а `issue_token` возвращал `None`
# из-за отсутствия библиотеки. Сообщение обвиняло **не то место**: человек пошёл
# бы чинить карточку, а чинить надо было зависимости.
#
# Локально дефект не воспроизводился — и это ровно тот случай, когда «у меня
# работает» опаснее всего: разница между машинами была в одной строке.
#
# Версия та же, что у `tk-assist-api` (`PyJWT[crypto]==2.13.0`), чтобы подпись и
# проверка не разошлись.
